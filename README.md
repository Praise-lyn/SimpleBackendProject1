## Featured Systems

### DoxaPay: Microfinance Core Banking Backend

![Microfinance](https://img.shields.io/badge/Domain-Microfinance-167D8D?style=flat-square)
![Core Banking](https://img.shields.io/badge/System-Core%20Banking-365E9D?style=flat-square)
![Backend](https://img.shields.io/badge/Focus-Backend-C05A35?style=flat-square)

**Problem**

- Microfinance operations need a dependable way to manage customer and account data alongside financial workflows.
- Financial records and business rules must remain consistent as transactions move through the system.

**Approach**

- Center the backend on clear API boundaries for core banking workflows and related data.
- Model customer, account, and transaction records to support traceable, consistent operations.
- Apply validation and controlled workflow transitions at the service boundary.

### Bokku Supermarket: Inventory Management Platform

![Retail](https://img.shields.io/badge/Domain-Retail-167D8D?style=flat-square)
![Inventory](https://img.shields.io/badge/System-Inventory%20Management-365E9D?style=flat-square)
![Platform](https://img.shields.io/badge/Focus-Platform-C05A35?style=flat-square)

**Problem**

- Supermarket teams need a reliable view of products and stock as inventory changes across day-to-day operations.
- Incomplete or outdated stock records make it harder to coordinate replenishment and make informed decisions.

**Approach**

- Organize the platform around a consistent product catalog and current inventory records.
- Represent stock changes as explicit operational updates to make inventory easier to maintain and review.
- Expose the core workflows through clear interfaces that can support staff-facing tools and reporting.
